# First Batch — Caffeine-Free Energy Drink Landing Page

A campaign landing page with a single goal: get visitors to sign up for a free first-batch case of a caffeine-free, gluten-free energy drink.

- One headline, two supporting lines, one email form — no other links
- Emails are validated and stored with a timestamp; duplicates are treated as already signed up
- Visitors see a confirmation immediately after signing up

Built with TanStack Start (React) and Lovable Cloud.
